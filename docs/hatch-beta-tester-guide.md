# Hatch beta — tester guide

You are trying Hatch before it is installed on a firm’s own hardware. This build runs the models on cloud test hardware (RunPod), not on a box in your office. Please don’t upload confidential client files.

Your link: https://hatch-os-beta.vercel.app

You will get a code that looks like `HATCH-XXXX`. That code is your sign-in. Don’t post it in a group chat.

## Install it on your phone

**iPhone**

1. Open the link in Safari.
2. Tap the Share button.
3. Tap Add to Home Screen, then Add.
4. Open Hatch from the icon.

**Android**

1. Open the link in Chrome.
2. Tap the menu (three dots).
3. Tap Install app, or Add to Home screen.
4. Open Hatch from the icon.

## Sign in

1. Open Hatch.
2. Read the beta note. It stays until you dismiss it.
3. Type your code and tap Sign in.
4. There is no second code. If the page asks for a six-digit authenticator code, you are not on the tester link.

## Please try these

1. **Create an agent.** Tap +, give it a name, a short description, and a color, then Create. You should land in its chat, and it should still be in the list if you go back.
2. **Talk to it.** Send two or three messages. Send the next one while the first reply is still coming. Leave the chat and come back. The messages should still be there.
3. **Attach a document.** In a chat, tap +, then Choose File, and pick something that is not confidential (a sample note is enough).
4. **Try voice.** Tap the blue waveform button. It opens a voice screen. You can close it with the X. Dictation uses your phone’s speech service when the phone has one.
5. **Ask Operations to list files.** Open Operations and ask it to list the files in its file room. You should see a short tool line and some sample file names. Those files are a sample firm, not a real client.
6. **Open Settings.** Tap your initials. Look at Vault, Permissions, and Hatch hardware. You can add a sample vault item. Don’t put a real password in it.

## What we want to know

- Where you got stuck, or where something felt slow or unclear.
- Whether a reply disappeared, repeated, or never arrived.
- Whether the screen jumped, zoomed, or sat under the keyboard.
- Anything that looked like another company’s product or a real client’s files.

## Send it from the app

Tap **Send feedback** in Settings, or the bug button in a chat. Say what you were doing, in a sentence or two. A screenshot is optional. Your tester name, the page, and the phone’s browser are attached for us. You don’t need to email anyone.
